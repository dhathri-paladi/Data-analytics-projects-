# Agent Behavior Analysis using NLP

## Overview
Developed a system to analyze call center agent interactions using speech-to-text and NLP techniques. The project classifies agent behavior based on politeness, emotion, and keyword analysis.

## Tools & Techniques
- Python, NLP (SpaCy, NLTK)
- Speech-to-Text APIs
- Pandas, scikit-learn, Matplotlib

## Key Features
- Audio to text conversion using speech recognition
- Emotion and sentiment tagging of agent responses
- Politeness scoring using rule-based and ML techniques
- Stored processed outputs in SQL for reporting

## Impact
Helps improve customer service by identifying agent strengths, weaknesses, and behavioral trends through automated analysis.
