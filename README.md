# Data Analytics & Data Science Portfolio
Welcome to my portfolio of real-world projects in data analytics and data science. This repository showcases hands-on work in forecasting, recommendation systems, NLP, dashboarding, and classification using industry-relevant tools and techniques.

---

## 📁 Projects Overview

### 🔹 [Weather Forecasting](./weather-forecasting/)
Time series forecasting using ARIMA, SARIMA, and LSTM models to predict temperature trends for 9 Indian states. Includes Power BI dashboard.

### 🔹 [Book Recommendation System](./book-recommender/)
Hybrid recommender system using content-based, collaborative, popularity-based, and mood-based filters. Built with Python, SQL, and Flask.

### 🔹 [Cryptocurrency Analysis](./crypto-analysis/)
Exploratory analysis and dashboarding of Bitcoin & Ethereum data using Python and Power BI.

### 🔹 [Food Retail Dashboard](./food-retail/)
Interactive Power BI dashboard analyzing food retail sales, top categories, and discount patterns.

### 🔹 [Personal Financial Analytics](./finance-analysis/)
Rule-based engine categorizing expenses into needs, wants, and savings using 34+ financial logic rules. Built for individuals across life stages.

### 🔹 [Agent Behavior Analysis](./agent-behavior-analysis/)
NLP-based classification of call center agent interactions using speech-to-text, sentiment scoring, and politeness analysis.
