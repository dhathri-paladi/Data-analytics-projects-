# Weather Forecasting

## Overview
Developed a time series forecasting system to predict temperature trends for 9 Indian states using historical weather data.

## Tools & Techniques
- Python, Pandas, NumPy
- ARIMA, SARIMA, LSTM
- Power BI for dashboard visualization

## Key Features
- 15-day forecasting with 95.74% accuracy
- Visual representation using Power BI
- Comparative analysis of traditional and deep learning methods
